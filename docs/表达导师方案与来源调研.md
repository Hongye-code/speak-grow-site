# 表达导师：词库方案与来源调研

## 结论

不做一个让用户自己翻找的“大词库”，而做一个嵌在练习报告里的 **表达导师**：它读懂用户本轮要表达的主题、原话和目标，给出少量可立刻复练的表达升级。

对外价值主张：**说完一次，马上知道哪句话可以说得更准、更有画面、更有说服力。**

## 用户闭环

| 时点 | 用户看到什么 | 系统动作 | 目的 |
| --- | --- | --- | --- |
| 开始前 | 主题表达包 | 按场景显示 4-6 个可选表达方向 | 降低“没话可说”的压力，不堆词。 |
| 练习中 | 中央计时、转写和一个当前目标 | 不主动弹出大量替换词；只在暂停或用户主动查看时给提示 | 不打断思路。 |
| 结束后 | `你原来怎么说` / `可以怎样升级` / `为什么更好` | 只挑 3 处最值得改的表达 | 让提升一眼可见。 |
| 60 秒复练 | 一条必须用上的升级表达 | 记录是否完成复练 | 把“看懂”变成“会用”。 |
| 下次进入 | 我的表达资产 | 复习已掌握的表达，而非重新背词 | 形成长期复利。 |

## 三种表达升级

| 类型 | 解决的问题 | 示例 |
| --- | --- | --- |
| 模糊变具体 | “很好、很多、提升、影响”没有信息量 | `效率提升了` -> `减少了反复切换工具造成的注意力损耗` |
| 叙述变有观点 | 只有现象，没有立场 | `AI 工具很多` -> `问题不在于工具不足，而在于工具切换持续切碎了注意力` |
| 结论变有行动 | 听众听完不知道怎么办 | `所以要提高效率` -> `先固定一个工作流，再决定是否引入下一件工具` |

## 首版内容结构

| 层级 | 首版范围 | 用法 |
| --- | --- | --- |
| 场景 | 职场面试、深度演讲、主题表达 | 决定语气和结构。 |
| 表达目的 | 说明、比较、解释原因、提出观点、举例、收束行动 | 决定用户此刻需要哪类语言。 |
| 主题包 | AI 与效率、学习成长、工作协作、职业面试、日常观点 | 每个主题包提供高频概念、动词、对比句和结尾句式。 |
| 表达卡 | 每张卡只含：适用场景、常见弱说法、升级方向、原创例句、复练句 | 作为报告和复练的最小单位。 |

## 2.0 半小时实现边界

| 本次做 | 不做 | 原因 |
| --- | --- | --- |
| 先写 36 张原创表达卡：3 场景 x 6 目的 x 2 张 | 导入数万词的完整词典 | 词越多，选择成本越高。 |
| 对转写稿做重复词、空泛词和填充词统计 | 假装理解所有语境的实时改写 | 静态网页的规则报告必须保持可解释。 |
| 报告只给 3 个“原句 -> 升级句 -> 60 秒复练” | 虚构“词汇量提升 63%”之类总分 | 提升感要来自可核对的前后对照。 |
| 复用现有 AI 教练提示词，增加“表达导师”段落 | 前端直接调用大模型 API | 不能把 Key 放进公开网页。 |

## 后续升级

| 阶段 | 新能力 | 前提 |
| --- | --- | --- |
| 2.1 | 我的表达资产库、掌握次数和主题复习 | 有稳定的本地记录格式。 |
| 2.2 | 语义候选和个性化改写 | 后端或用户自带模型 Key，避免公开 Key。 |

## 来源与版权边界

| 来源 | 已核对信息 | 适合做什么 | 不做什么 |
| --- | --- | --- | --- |
| [OpenHowNet](https://github.com/thunlp/OpenHowNet) | GitHub 标注 MIT；项目提供词义、词性、情感倾向、例句和语义关系查询 | 后续为一个词找到语义相近或上下位的候选 | 不把候选词直接当作“更会说话”的答案。 |
| [JioNLP](https://github.com/dongrixinyu/JioNLP) | GitHub 标注 Apache-2.0；提供中文 NLP 预处理与解析能力 | 分词、短语与文本规则统计的技术参考 | 不直接把第三方词典整体复制到公开网页。 |
| [THUOCL](https://github.com/thunlp/THUOCL) | 清华中文词库项目，可作为领域词覆盖度的调研来源 | 后续核对主题词的常见性和领域覆盖 | 本轮不导入或再分发，先单独核验每个数据文件许可。 |
| 《修辞学发凡》与《汉语修辞学》 | 作为修辞分类与人工编辑参考 | 指导“何时更具体、何时对比、何时收束”的表达卡设计 | 不复制书中长段落、例句或词表。 |
| [[01-可追溯的方法卡|MIT How to Speak 方法卡]] | 当前项目已有可追溯训练结构 | 让表达卡服务于开场、观点、例子和结尾 | 不把语言润色取代结构训练。 |

## 验收标准

1. 用户练完后 10 秒内能看懂自己最该改的三处表达。
2. 每一处建议都能对应原稿中的具体句子，而不是泛泛而谈。
3. 用户只需选一条就能完成 60 秒复练。
4. 词库不产生 AI 腔、套话或生僻词堆砌；表达仍然像用户本人。
