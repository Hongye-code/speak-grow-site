# 讲清楚 / SPEAK BETTER

一个面向大众的中文口语表达训练网页。

## 3.0：职场力量练习

`/v3/` 是一页无后端的 60 秒职场沟通练习：从一个难开口的场景出发，推荐一项力量动作，支持兼容浏览器的实时转写和手动逐字稿输入，最后给出透明的本地规则反馈与一次复练。

| 说明 | 3.0 的做法 |
| --- | --- |
| 隐私 | 不上传、不保存音频；记录仅保存在当前浏览器。 |
| 反馈 | 只检查逐字稿可见信号，明确标注为本地规则反馈，不伪装成 AI 评价。 |
| 开源范围 | `v3/` 中的原创源码采用 [MIT License](v3/LICENSE)。不包含第三方图片、题库或文案。 |

打开网页，选择场景和题目，直接开始三分钟表达。结束后，页面会给出练习时长、字数、填充词占比，以及三条可以马上用于 60 秒复练的“表达导师”建议。

## 当前功能

| 功能 | 说明 |
| --- | --- |
| 三种训练模式 | 职场面试、深度演讲、主题表达。 |
| 原创随机题目 | 不知道讲什么时，点击按钮后随机抽取一题。 |
| 居中练习舞台 | 3 分钟计时、录音、实时转写兼容层和原稿输入。 |
| 表达导师报告 | 从原句出发，给出更具体、更有观点或更有行动感的复练建议。 |
| 本地记录 | 练习记录只保存在当前浏览器；音频由用户自行下载。 |
| AI 深度反馈 | 页面复制提示词，用户粘贴到自己常用的大模型；不在前端存放 API Key。 |

## 本地预览

这是一个无构建步骤的静态网页。进入项目目录后运行：

```bash
python3 -m http.server 4173
```

再访问 `http://127.0.0.1:4173`。

## 边界

- 浏览器对实时中文转写的支持不同；不支持时可直接输入或粘贴转写稿。
- 本项目不承诺通过一次练习测量或保证表达能力提升；它提供的是可见的原句对照和可执行的复练动作。
- 本仓库不包含外部讲座的逐字稿、书籍原文或其他受版权保护的资料。
