# 讲清楚 V3-4「职场表达能力金字塔」

本包是 V3-4 的正式运行源码。它完整继承此前 V3-4 的七类训练、录音下载、转写降级、报告、成长、设置、BYOK、隐私与版权能力，并新增 60 秒表达挑战与七级训练地图。

## 本次正式更新

首次进入只需完成固定的一题：`领导突然问：你最近在忙什么？请用 60 秒说明。` 用户可本地录音、浏览器转写或补写原稿。结果显示初步训练段位、距离下一层差几分和唯一行动句；同题复练后如实显示分数变化并可下载挑战海报。评分、原稿和海报均在本地浏览器完成。

## 本次新增

| 模块 | 正式实现 |
| --- | --- |
| 训练地图 | 首页只展示当前关卡、距下一段位的真实训练证据与一个主操作。 |
| 七级表达训练 | 七级均有真实训练入口；每级 100 道题，共 700 道。训练段位仅是练习参照，不是职位、资格或社会地位判断。 |
| 本地题签 | 当前级别可领取随机题签；服务端榜单未启用时，自动降级为本地练习，不阻断训练。 |
| 七类训练 | 即兴表达、闲聊训练、职场表达、求职面试、讲故事、主题表达、深度演讲，按能力要求由低到高排列。 |
| 资料索引 | 保留自信专训 18 条资料，并追加第 4 至 7 级的谈判、会议引导、战略叙事与危机沟通索引。 |
| VAD 辅助 | 本地录音时仅提示开始说话或停顿；加载失败不影响录音、转写或手动原稿。 |
| whisper.cpp | 固定源码与 MIT 许可，作为未来本地离线转写储备；未下载模型、不部署、不上传音频。 |

## 严格评分与隐私

- 首次测级为本地训练起点，不计入周榜，也不判定真实职业能力。
- 分数由本轮实际原稿的五维量表计算，浏览器不接受外部指定分数。
- 题签服务不可用时自动发放本地随机题；本地题签不会提交匿名榜单。
- 公开匿名榜单、服务端重算、题签时效与用户删除接口保留为后续 D1 启用能力；启用前不展示榜单、百分位或虚构对手。
- 音频始终不上传；原稿和训练记录默认只保留在当前浏览器。
