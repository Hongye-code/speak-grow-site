# 讲清楚 V3-3：连续训练

本版从“职场讲故事”基础材料完整继承。陈红叶已选定候选 E「连续训练」并将其正式化；候选 A-E 保留原样，本目录是后续版本的唯一源码父本。

## 本次新增

| 模块 | 正式实现 |
| --- | --- |
| 职场闲聊 | 第六类训练档案，100 个具体职场场景，破冰、倾听回应、60 秒与复练。 |
| 职场面试 | 保留常规面试 100 题；新增可发现的“自信专训”。 |
| 自信专训 | 顶层只有理论学习、实战练习；理论学习下再给快速准备、使用资料。 |
| 快速准备 | 以 `Think Faster, Talk Smarter` 精读页的 Calm、Redefine、Structure 为练习前心理准备，不把紧张定义为能力不足。 |
| 使用资料 | 18 条来源：10 本书、5 个核心公开来源、3 个练习灵感入口。 |
| 实战闭环 | 20 个不同真实面试场景，各自带第一句、卡点和回答路线；填结果、动作、细节后完成 60 秒、追问、改一句、复练。 |
| 本地音频 | 六类训练均可开始、暂停、结束并主动下载 WebM；音频不上传，原稿始终可编辑。 |
