## 技术栈

- 纯静态 HTML/CSS/JS，无构建依赖
- Lucide 图标库（CDN）
- 响应式设计

## 四大训练模块

1. **费曼技巧** — 用最简单的话解释复杂概念
2. **卡片盒笔记法** — 原子化知识卡片
3. **苏格拉底提问** — 深度追问训练
4. **自由写作** — 限时自由表达
